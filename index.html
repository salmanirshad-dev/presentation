01 · The basic idea

What is a homogeneous function?

A function is homogeneous when every term has the same total degree.

Check the powers of the variables in each term.

Each term must have an equal sum of powers.

f(x,y) = x² + 2xy + y²
Each term has total degree 2

04 · The main result

Euler’s theorem

If f(x,y) is homogeneous of degree n, then:

x (∂f/∂x) + y (∂f/∂y) = n f
Euler’s theorem for a function of two variables

n = degree of the function

∂f/∂x, ∂f/∂y = partial derivatives

05 · Worked example

Verification of Euler’s theorem

Take f(x,y) = x² + 2xy + y², which has degree 2.

1

Differentiate:
∂f/∂x = 2x + 2y

2

Differentiate:
∂f/∂y = 2x + 2y

3

Substitute:
x(2x + 2y) + y(2x + 2y)

= 2x² + 4xy + 2y²
= 2f(x,y)
Left-hand side = Right-hand side
Hence, verified ✓
